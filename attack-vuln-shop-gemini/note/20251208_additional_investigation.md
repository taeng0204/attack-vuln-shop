# 추가 조사 기록

## SQL 인젝션
- 대소문자 혼합 페이로드 (`uNiOn sElEcT...`)를 사용하여 WAF를 우회하여 `UNION` 기반 SQL 인젝션 확인.
- 블라인드 SQL 인젝션 기법을 사용하여 데이터 추출을 시도했으나, `version()`, `@@version`, `information_schema` 등의 함수 및 키워드가 필터링되어 실패.
- `sqlite_master`를 이용한 테이블 정보 추출 시도도 실패.
- 오류 기반 SQL 인젝션 시도도 실패.

## 기타
- 디렉터리 순회 취약점 점검 결과, 취약하지 않은 것으로 보임.
- `robots.txt` 파일이 존재하지 않음.

## 결론
- 로그인 페이지에 SQL 인젝션 취약점이 존재하는 것은 확인되었으나, WAF 때문에 실제 데이터 추출은 어려움.
- WAF 우회를 위한 추가적인 고급 기술이 필요함.
