# 초기 정보 수집 (Reconnaissance)

## 1. 초기 요청 및 응답 분석

- **명령어**: `curl -v -H "X-Forwarded-For: 10.0.0.103" "http://192.168.0.28:3000"`
- **주요 응답 헤더**:
  - `HTTP/1.1 200 OK`
  - `X-Powered-By: Express`: Node.js Express 프레임워크 사용 확인.
- **HTML 본문 분석**:
  - 주요 페이지 링크 확인: `/`, `/board`, `/login`, `/signup`
  - 흥미로운 지점: `SEC: v1` 이라는 텍스트 존재. 보안 레벨과 관련된 기능으로 추정됨.

## 2. 식별된 기술 스택

- **Backend**: Node.js (Express)
- **Frontend**: 기본 HTML, CSS

## 3. 초기 발견 사항 및 추론

- **Node.js/Express 기반 취약점**: Express 프레임워크와 관련된 일반적인 취약점(예: 미들웨어 설정 오류, 템플릿 엔진 취약점, 프로토타입 오염) 존재 가능성을 염두에 둠.
- **'SEC: v1' 파라미터**: 이 값은 쿠키, 헤더, 또는 쿼리 파라미터를 통해 제어될 수 있음. 만약 이 값을 변경하여 보안 메커니즘을 우회할 수 있다면, 이는 심각한 취약점일 수 있음. 다음 단계에서 이 파라미터 조작을 시도할 필요가 있음.
