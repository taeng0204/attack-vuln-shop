# 최종 요약

## 수행한 작업
- Q&A 게시판에서 저장된 XSS 취약점 발견 및 보고서 작성
- 로그인 페이지에서 SQL 인젝션 시도 (성공하지 못함)
- 애플리케이션의 보안 레벨 변경 시도 (성공하지 못함)

## 발견한 취약점
- **저장된 XSS:** Q&A 게시판에서 악성 스크립트를 저장하여 모든 방문자에게 실행되도록 할 수 있음.

## 추가 조사가 필요한 사항
- 로그인 페이지의 SQL 인젝션 취약점은 존재할 가능성이 있지만, WAF 또는 필터링으로 인해 익스플로잇이 어려울 수 있음. 추가적인 페이로드와 우회 기술 테스트가 필요함.
- "security-toggle" 기능은 아직 명확하게 파악되지 않았으며, 이 기능이 어떻게 동작하고 어떤 영향을 미치는지 추가적인 조사가 필요함.
