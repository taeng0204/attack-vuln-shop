## 초기 정찰

`curl`을 사용하여 웹사이트의 메인 페이지를 확인하고 기본적인 응답을 분석한다. `X-Forwarded-For` 헤더를 포함하여 요청을 보낸다.

### 메인 페이지 분석 결과
- **주요 기능:** 쇼핑(`Shop`), Q&A 게시판(`/board`), 로그인(`/login`), 회원가입(`/signup`)
- **흥미로운 지점:**
    - **Q&A 게시판 (`/board`):** 사용자 입력이 많아 SQL 인젝션, XSS 등의 주요 타겟.
    - **로그인 페이지 (`/login`):** 인증 우회, SQL 인젝션 테스트 대상.
    - **보안 레벨 (`SEC: v1`):** 조작 가능성이 있는지 확인 필요. 쿠키나 파라미터를 통해 제어될 수 있음.
- **기술 정보:**
    - CSS: `/style.css`
    - 이미지: `/images/` 디렉토리
