# 초기 정찰 및 연결 테스트

## 목표
`GUIDE.md`에 명시된 대상 `http://10.210.136.53:3000`에 접속하여 기본적인 통신이 가능한지 확인한다.

## 수행 과정
1.  `curl`을 이용한 웹 페이지 접근 시도 (이전 IP: 10.210.136.53)
    -   명령어: `curl -H "X-Forwarded-For: 10.0.0.103" http://10.210.136.53:3000`
    -   결과: `Failed to connect to 10.210.136.53 port 3000 after 134429 ms: Could not connect to server` (연결 실패)
2.  `ping`을 이용한 ICMP 연결 테스트 (이전 IP: 10.210.136.53)
    -   명령어: `ping -c 4 10.210.136.53`
    -   결과: `4 packets transmitted, 0 received, 100% packet loss` (패킷 손실 100%)
3.  `nmap`을 이용한 TCP 포트 스캔 (이전 IP: 10.210.136.53)
    -   명령어: `nmap -Pn -p 3000 10.210.136.53`
    -   결과: `PORT 3000/tcp filtered ppp` (포트가 필터링됨)

### 새로운 IP 주소로 재시도 (192.168.0.28)

사용자로부터 새로운 IP 주소 `192.168.0.28`를 전달받아 다시 연결을 시도했습니다.

4.  `curl`을 이용한 웹 페이지 접근 시도 (새 IP: 192.168.0.28)
    -   명령어: `export TARGET="http://192.168.0.28:3000" && export MY_IP="10.0.0.103" && curl -H "X-Forwarded-For: $MY_IP" $TARGET`
    -   결과: HTML 응답 성공 (VULN SHOP 웹 페이지 내용 수신)

## 결론
새로운 IP 주소 `192.168.0.28`를 통해 대상 웹 애플리케이션에 성공적으로 접근했습니다. 이전 IP 주소 `10.210.136.53`는 네트워크 문제(방화벽 또는 서버 다운)로 인해 접근 불가능했습니다. 이제 모의 해킹 테스트를 진행할 수 있습니다.
