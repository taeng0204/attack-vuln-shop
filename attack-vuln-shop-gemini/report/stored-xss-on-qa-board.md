# 취약점 보고서: 저장된 크로스 사이트 스크립팅 (XSS)

- **취약점:** 저장된 크로스 사이트 스크립팅 (XSS)
- **위치:** Q&A 게시판 (`/board`)
- **날짜:** 2025-12-08

## 설명
Q&A 게시판에 악의적인 스크립트를 포함한 게시물을 작성할 수 있습니다. 이 스크립트는 해당 페이지를 방문하는 모든 사용자의 브라우저에서 실행됩니다.

## 재현 단계
1. `http://10.210.136.53:3000/board`로 이동합니다.
2. "Your Question" 텍스트 영역에 다음 페이로드를 입력합니다.
   ```html
   <script>alert('XSS')</script>
   ```
3. "Post Question" 버튼을 클릭합니다.
4. 게시판을 다시 방문하면 `alert` 창이 나타납니다.

## 영향
- 악의적인 스크립트 실행
- 세션 쿠키 탈취
- 사용자 리디렉션
- 페이지 내용 조작
