# 취약점 보고서: 블라인드 SQL 인젝션

- **취약점:** 블라인드 SQL 인젝션
- **위치:** 로그인 페이지 (`/login`)
- **날짜:** 2025-12-08

## 설명
로그인 페이지의 `username` 파라미터에 SQL 인젝션 취약점이 존재합니다. 대소문자를 혼합한 SQL 키워드를 사용하여 WAF를 우회할 수 있으며, 이를 통해 `UNION` 기반의 블라인드 SQL 인젝션 공격이 가능합니다.

## 재현 단계
1. `http://10.210.136.53:3000/login`로 이동합니다.
2. `username` 필드에 다음 페이로드를 입력합니다.
   ```sql
   ' uNiOn sElEcT NULL, NULL, NULL, NULL--
   ```
3. `password` 필드에 아무 값이나 입력하고 "Login" 버튼을 클릭합니다.
4. 서버가 "Found. Redirecting to /" 응답을 반환하면 취약점이 확인된 것입니다.

## 영향
- 데이터베이스 스키마 및 데이터 유출 가능성 (WAF 우회 필요)
- 인증 우회 가능성

## 참고
- 현재 WAF가 `information_schema` 접근 및 `version()`과 같은 함수 실행을 차단하고 있어, 실제 데이터 추출을 위해서는 추가적인 WAF 우회 기술이 필요합니다.
