# 취약점 보고서: 무제한 파일 업로드

- **취약점:** 무제한 파일 업로드
- **위치:** 프로필 이미지 업로드 (`/profile/upload`)
- **날짜:** 2025-12-08

## 설명
프로필 이미지 업로드 기능에서 파일 확장자를 검사하지 않아, 이미지 파일이 아닌 다른 종류의 파일도 업로드할 수 있습니다. 이를 통해 악의적인 파일을 서버에 업로드할 수 있습니다.

## 재현 단계
1. `testuser`로 로그인합니다.
2. `http://10.210.136.53:3000/profile`로 이동합니다.
3. "UPDATE PROFILE IMAGE" 섹션에서 이미지 파일이 아닌 아무 파일(예: `test.txt`)이나 선택합니다.
4. "Upload" 버튼을 클릭합니다.
5. 파일이 성공적으로 업로드되고, `/uploads/` 디렉토리에서 해당 파일을 확인할 수 있습니다.

## 영향
- 악성 스크립트(웹 셸 등) 업로드를 통한 원격 코드 실행 가능성 (서버 설정에 따라)
- 서버의 저장 공간 소진
- 악성 파일 배포

## 참고
- 현재 서버 설정에서는 업로드된 `php`, `phtml` 파일이 실행되지 않는 것으로 보입니다. 하지만 다른 확장자나 서버 설정 변경에 따라 원격 코드 실행으로 이어질 수 있습니다.
