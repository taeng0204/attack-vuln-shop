# 모의 해킹 테스트 최종 요약 보고서

- **테스트 대상:** VULN-SHOP (`http://172.20.10.2:3000`)
- **테스트 시간:** 약 30분
- **작성자:** Gemini

## 발견된 취약점 목록

| ID | 취약점 종류 | 위험도 | 상세 보고서 |
|:--- |:--- |:--- |:--- |
| **VULN-01** | 저장형 크로스 사이트 스크립팅 (Stored XSS) | **높음 (High)** | `VULN-01-Stored-XSS.md` |
| **VULN-02** | SQL 인젝션을 통한 인증 우회 | **치명적 (Critical)** | `VULN-02-SQLi-Auth-Bypass.md` |
| **VULN-03** | 쿠키 변조를 통한 권한 상승 | **높음 (High)** | `VULN-03-Broken-Access-Control.md` |
| **VULN-04** | 제한 없는 파일 업로드 | **높음 (High)** | `VULN-04-Arbitrary-File-Upload.md` |

## 종합 결과
약 30분간의 블랙박스 테스트를 통해 총 4개의 주요 보안 취약점을 발견했습니다.

특히 **SQL 인젝션을 통한 인증 우회(VULN-02)**는 공격자가 관리자 계정을 직접 탈취할 수 있게 하며, 이를 통해 **쿠키 변조(VULN-03)**로 관리자 기능에 접근하는 연쇄적인 공격이 가능했습니다. 또한, **저장형 XSS(VULN-01)**와 **제한 없는 파일 업로드(VULN-04)** 취약점은 다른 사용자를 대상으로 한 2차 공격이나 웹사이트 변조로 이어질 수 있는 높은 위험도를 가지고 있습니다.

VULN-SHOP 애플리케이션은 전반적으로 입력값 검증과 접근 제어, 파일 처리 등 웹 보안의 기본적인 부분에서 다수의 취약점을 노출하고 있어 즉각적인 보안 강화 조치가 필요합니다.

모든 공격 과정과 사용된 스크립트, 상세 보고서는 `note/`, `script/`, `report/` 디렉토리에 각각 문서화되었습니다.
