# 취약점 보고서: VULN-01 - 저장형 크로스 사이트 스크립팅 (Stored XSS)

- **취약점 ID:** VULN-01
- **종류:** 저장형 크로스 사이트 스크립팅 (Stored Cross-Site Scripting)
- **위험도:** 높음 (High)
- **발견 날짜:** 2025-12-11

## 요약
VULN-SHOP의 Q&A 게시판(`/board`)에는 저장형 XSS 취약점이 존재합니다. 사용자가 입력한 내용이 서버에서 적절히 필터링(Sanitization)되지 않고 데이터베이스에 저장된 후, 페이지에 그대로 출력되어 악의적인 스크립트 실행이 가능합니다.

## 재현 과정
1. Q&A 게시판(`http://172.20.10.2:3000/board`)에 접속합니다.
2. 'Your Question' 입력란에 아래와 같은 XSS 페이로드를 입력하고 'Post Question' 버튼을 클릭합니다.
   ```html
   <script>alert('XSS')</script>
   ```
3. 게시판 페이지에 다시 접속하면, 브라우저에서 'XSS'라는 내용의 경고창(alert)이 실행됩니다.

## 상세 설명
공격자는 이 취약점을 이용해 다른 사용자의 브라우저에서 임의의 자바스크립트 코드를 실행할 수 있습니다. 이를 통해 세션 쿠키 탈취, 악성 사이트로의 리디렉션, 페이지 내용 조작 등 심각한 피해를 유발할 수 있습니다.

HTML 소스 코드에서 아래와 같이 사용자의 입력이 그대로 출력되는 것을 확인할 수 있습니다.
```html
<div class="post-content">
    <!-- VULNERABILITY: Unescaped output allows XSS (except v3) -->
    
                <script>alert('XSS')</script>
                                    
</div>
```
주석에 따르면, 이 취약점은 'v3' 보안 레벨에서는 존재하지 않을 수 있습니다.

## 권고 사항
1. **입력값 검증 및 출력값 이스케이프(Escaping):**
   - 서버 측에서 사용자 입력을 받을 때, 스크립트 태그나 위험한 HTML 코드를 필터링해야 합니다.
   - 데이터베이스에 저장된 값을 웹 페이지에 출력할 때, HTML 엔티티로 이스케이프하여 브라우저가 코드로 해석하지 않고 텍스트로만 인식하도록 해야 합니다. (e.g., `<`를 `&lt;`로 변경)
2. **보안 레벨 'v3' 적용:** 코드 주석에서 언급된 'v3' 보안 레벨이 이 문제를 해결한다면, 해당 기능이 어떻게 활성화되는지 확인하고 기본값으로 적용하는 것을 고려해야 합니다.
