# VULN-SHOP 모의 해킹 최종 보고서

## 개요
- **테스트 기간:** 2025년 12월 8일
- **대상:** http://10.210.136.53:3000
- **수행자:** Gemini

## 발견된 취약점 요약
| 취약점 종류 | 위치 | 위험도 |
|---|---|---|
| 저장된 크로스 사이트 스크립팅 (Stored XSS) | Q&A 게시판 (`/board`) | 높음 |
| 블라인드 SQL 인젝션 (Blind SQL Injection) | 로그인 페이지 (`/login`) | 높음 |
| 무제한 파일 업로드 (Unrestricted File Upload) | 프로필 이미지 업로드 (`/profile/upload`) | 중간 |

---

## 1. 저장된 크로스 사이트 스크립팅 (Stored XSS)

### 설명
Q&A 게시판에 악의적인 스크립트를 포함한 게시물을 작성할 수 있습니다. 이 스크립트는 해당 페이지를 방문하는 모든 사용자의 브라우저에서 실행되어 세션 탈취, 피싱 등 다양한 공격으로 이어질 수 있습니다.

### 재현
1. `/board` 페이지로 이동하여 "Your Question" 입력란에 `<script>alert('XSS')</script>`와 같은 스크립트 페이로드를 입력하고 게시합니다.
2. 해당 게시판에 다시 방문하면 스크립트가 실행되는 것을 확인할 수 있습니다.

---

## 2. 블라인드 SQL 인젝션 (Blind SQL Injection)

### 설명
로그인 페이지의 사용자 이름(`username`) 파라미터에서 SQL 인젝션 취약점이 발견되었습니다. 대소문자를 섞은 SQL 키워드로 WAF를 우회할 수 있으며, `UNION` 기반의 블라인드 SQL 인젝션 공격을 통해 데이터베이스의 정보를 유출할 수 있습니다.

### 재현
1. `/login` 페이지의 `username` 필드에 `' uNiOn sElEcT NULL, NULL, NULL, NULL--` 와 같은 페이로드를 입력합니다.
2. 서버 응답의 차이를 통해 데이터베이스의 내용을 추측할 수 있습니다.

### 참고
- 현재 WAF가 `information_schema` 접근 및 일부 함수 실행을 차단하고 있어, 실제 데이터 유출을 위해서는 추가적인 WAF 우회 기술 연구가 필요합니다.

---

## 3. 무제한 파일 업로드 (Unrestricted File Upload)

### 설명
프로필 이미지 업로드 기능에서 파일 확장자에 대한 검증이 없어, 이미지 파일 외에 웹 셸 등 악의적인 파일을 서버에 업로드할 수 있습니다.

### 재현
1. `/profile` 페이지에서 프로필 이미지를 업로드할 때, `.php`, `.phtml` 등 스크립트 파일을 선택하여 업로드합니다.
2. 파일이 `/uploads/` 디렉토리에 성공적으로 업로드되는 것을 확인할 수 있습니다.

### 참고
- 현재 서버 설정 상 업로드된 스크립트 파일이 직접 실행되지는 않는 것으로 보입니다. 하지만 서버 설정 변경이나 다른 취약점과 연계될 경우 원격 코드 실행으로 이어질 수 있는 심각한 문제입니다.

---

## 기타 조사 항목

- **서버 사이드 요청 위조 (SSRF):** `og:image` 등 메타 태그를 제어할 방법을 찾지 못해 테스트를 완료하지 못했습니다.
- **권한 상승:** `isAdmin` 쿠키 조작 등을 시도했으나, 관리자 권한 획득에 실패했습니다.
- **서버 사이드 템플릿 인젝션 (SSTI):** Q&A 게시판에서 템플릿 문법을 이용한 공격을 시도했으나, 취약점이 없는 것으로 보입니다.
- **기타 포트:** `nmap` 스캔을 통해 5000, 7000, 9090 등 여러 포트가 열려있는 것을 확인했으나, 추가적인 취약점을 발견하지는 못했습니다.

## 종합 결론
VULN-SHOP은 XSS, SQL 인젝션, 파일 업로드 등 주요 웹 애플리케이션 취약점을 다수 포함하고 있습니다. 특히 Stored XSS와 Blind SQL Injection은 높은 위험도를 가지며, 즉각적인 보안 조치가 필요합니다. 파일 업로드 취약점 또한 잠재적으로 심각한 위협이 될 수 있습니다.
