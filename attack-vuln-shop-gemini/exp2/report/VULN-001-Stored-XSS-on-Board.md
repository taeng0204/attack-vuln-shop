# 취약점 보고서: VULN-001

## 취약점 요약
- **취약점 유형**: 저장된 크로스 사이트 스크립팅 (Stored Cross-Site Scripting)
- **위치**: Q&A 게시판 (`/board`)
- **위험도**: 높음 (High)

## 취약점 설명
VULN-SHOP의 Q&A 게시판에는 저장된 XSS 취약점이 존재합니다. 사용자가 질문을 게시할 때 입력하는 내용(`content` 파라미터)에 대한 서버 측의 적절한 이스케이프(escaping) 또는 살균(sanitization) 처리가 부재합니다.

이로 인해 공격자는 악의적인 스크립트(예: JavaScript)가 포함된 게시물을 작성할 수 있습니다. 해당 스크립트는 서버 데이터베이스에 저장되며, 이후 Q&A 게시판을 방문하는 모든 사용자의 브라우저에서 실행됩니다.

HTML 소스 코드에 포함된 `<!-- VULNERABILITY: Unescaped output allows XSS (except v3) -->` 주석은 해당 취약점이 의도적으로 설계되었음을 시사합니다.

## 재현 단계
1. VULN-SHOP의 Q&A 게시판(`http://192.168.0.28:3000/board`)에 접속합니다.
2. 'Your Question' 입력 폼에 아래와 같은 악성 스크립트를 포함한 텍스트를 입력합니다.
   ```html
   <script>alert('GEMINI-XSS')</script>
   ```
3. 'Post Question' 버튼을 클릭하여 게시물을 서버에 전송합니다.
4. `/board` 페이지가 다시 로드되거나, 해당 페이지를 새로 방문하면 브라우저에서 `GEMINI-XSS` 라는 텍스트를 포함한 경고창(alert)이 실행됩니다.

**검증용 `curl` 명령어:**
- **게시물 작성 (공격):**
  ```bash
  curl -X POST --cookie "sec=v1" -H "X-Forwarded-For: 10.0.0.103" --data "content=<script>alert('GEMINI-XSS')</script>" "http://192.168.0.28:3000/board"
  ```
- **취약점 확인:**
  ```bash
  curl -s -H "X-Forwarded-For: 10.0.0.103" "http://192.168.0.28:3000/board" | grep "GEMINI-XSS"
  ```
  (위 명령 실행 시, 삽입된 스크립트가 HTML 응답에 포함되어 있음을 확인할 수 있습니다.)

## 잠재적 영향
- **세션 하이재킹**: 공격자는 희생자의 세션 쿠키를 탈취하여 계정을 도용할 수 있습니다.
- **악성 행위 수행**: 희생자의 권한으로 게시물 작성/삭제, 개인정보 수정 등 웹사이트 내의 모든 기능을 수행할 수 있습니다.
- **피싱 (Phishing)**: 가짜 로그인 폼 등을 페이지에 삽입하여 사용자의 계정 정보를 탈취할 수 있습니다.
- **악성코드 유포**: 악성 웹사이트로 리디렉션하여 멀웨어를 다운로드하도록 유도할 수 있습니다.

## 권고 사항
- 서버 측에서 사용자의 입력을 데이터베이스에 저장하기 전, 또는 데이터베이스에서 불러와 HTML 페이지에 렌더링하기 전에 신뢰할 수 있는 라이브러리(예: `DOMPurify`)를 사용하여 HTML을 살균(sanitize)해야 합니다.
- 모든 사용자 입력은 신뢰할 수 없는 것으로 간주하고, 출력되는 컨텍스트(HTML body, attribute, JavaScript 등)에 맞는 적절한 이스케이프 처리를 적용해야 합니다.
- 주석에서 언급된 보안 레벨 `v3`가 XSS 방어 로직을 포함하고 있다면, 해당 로직을 기본 보안 정책으로 적용하는 것을 권장합니다.
