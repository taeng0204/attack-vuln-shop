# 3단계: 발견 사항 요약

## 취약점 통계

| 심각도 | 개수 |
|--------|------|
| Critical (심각) | 4 |
| High (높음) | 8 |
| Medium (중간) | 6 |
| Low (낮음) | 2 |
| **총계** | **20** |

---

## 심각 취약점 (Critical)

### 1. SQL 인젝션 - 로그인 우회 + DB 덤프
- **위치**: POST /login
- **페이로드**: `admin' OR '1'='1' --`
- **영향**: 인증 우회, 전체 계정 탈취

### 2. 접근 제어 취약점 - 쿠키 조작
- **위치**: Cookie `isAdmin`
- **페이로드**: `isAdmin=true`
- **영향**: 관리자 권한 획득

### 3. 평문 비밀번호 저장
- **위치**: 데이터베이스 users 테이블
- **영향**: SQL 인젝션으로 모든 비밀번호 직접 추출

### 4. 사용자 검증 미흡
- **위치**: 인증 로직
- **영향**: 존재하지 않는 user_id로도 관리자 접근 가능

---

## 높음 취약점 (High)

### 5. IDOR
- **위치**: GET /order?id=
- **영향**: 타 사용자 주문 정보 열람

### 6. 저장형 XSS
- **위치**: POST /board
- **영향**: 세션 탈취, 피싱

### 7. 무제한 파일 업로드
- **위치**: POST /profile/upload
- **영향**: 악성 파일 호스팅

### 8. CSRF
- **위치**: 모든 POST 엔드포인트
- **영향**: 사용자 행동 유도

### 9. DB 스키마 노출
- **위치**: SQL 인젝션
- **영향**: 전체 테이블 구조 추출

### 10. 시간 기반 Blind SQL 인젝션
- **위치**: POST /login
- **영향**: 데이터 추출 가능

### 11. 2차 SQL 인젝션
- **위치**: POST /signup
- **영향**: 저장된 페이로드 실행

### 12. Polyglot 파일 업로드
- **위치**: POST /profile/upload
- **영향**: 파일 검증 우회

---

## 공격 성공 경로

```
[인증 우회] SQL 인젝션
      ↓
[권한 상승] 쿠키 조작 (isAdmin=true)
      ↓
[정보 탈취] IDOR + DB 덤프
      ↓
[지속성] XSS + 파일 업로드
```

## OWASP Top 10 매핑

| OWASP 2021 | 발견된 취약점 |
|------------|---------------|
| A01: 접근 제어 취약점 | 쿠키 조작, IDOR, CSRF |
| A02: 암호화 실패 | 평문 비밀번호 |
| A03: 인젝션 | SQL 인젝션, XSS |
| A04: 안전하지 않은 설계 | 파일 업로드, 비즈니스 로직 |
| A05: 보안 설정 오류 | 보안 헤더 누락 |
| A07: 식별 및 인증 실패 | Rate Limiting 없음 |
